# Simple TCP Port Scanner (C#)

Proste narzędzie konsolowe napisane w języku C# do skanowania portów TCP w określonym zakresie. Projekt stworzony w celach edukacyjnych.

## Funkcje
- Skanowanie wybranego adresu IP lub domeny.
- Predefiniowany zakres portów.
- Szybki mechanizm sprawdzania statusu portów (timeout).
- Kolorowane wyjście w konsoli (zielony wyróżniający otwarte porty).

## Wymagania
- [.NET SDK](https://dotnet.microsoft.com/)

##  Jak uruchomić?
1. Pobierz lub sklonuj projekt.
2. Otwórz folder projektu w terminalu.
3. Uruchom aplikację poleceniem:
   ```bash
   dotnet run

Narzędzie służy wyłącznie do celów edukacyjnych i powinno być używane na własnych hostach lub w kontrolowanych środowiskach testowych.
